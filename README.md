# Four Function Calculator

a simple four function calculator made in c. currently has capability for the four standard math operations, and equation memory where users can look at previously entered equations.

## how to run
make sure that these libraries are installed on your system: `stdio`, `stdlib`, `string`, `stdbool`, `ctype`

if you don't have them, try running this in your terminal (preffered linux or wsl)
```
$ sudo apt update
$ sudo apt install build-essential
```

this program doesn't have a specific method for compilation, however i mainly use gcc. with gcc in the terminal, run
```
$ gcc main.c -o main
```
in the project directory, then run
```
$ ./main
```
to start the program in the terminal.
